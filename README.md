# Snake Arcade

A standalone browser Snake game built with HTML, CSS, and JavaScript. No build step or dependencies are required.

## Play

Open `index.html` in a browser.

- Move: Arrow keys or WASD
- Pause/resume: Space
- Restart: Restart button
- Touch: Swipe on the game board

Eat fruit to grow and score points. Avoid the walls, yourself, and the two roaming hunters. Your best score is saved in local storage.
